NusaStat — a national statistics site for Indonesia: population, economy, health and education, with charts, a searchable and sortable table of all 38 provinces, a page for every indicator and every province, and a source and year on every figure. It runs offline in a web browser from its own static files, on desktop and on a phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or build the hand-in with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
